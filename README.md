# 标印 LabelPress

> 商品信息管理 + 条形码生成 + 标签打印（免安装便携版）

**LabelPress** 是一款基于 Electron 的桌面应用，专为零售、仓储、小型商超等场景设计。它提供商品数据的增删改查、多种条形码格式的自动生成与校验，以及可视化标签打印设计器，支持所见即所得的排版与直接打印。

---

## ✨ 功能特性

### 📦 商品管理
- **新增/编辑商品**：名称、SKU、分类、单位、价格、规格、备注等字段，表单内 Enter 直接保存
- **连续录入**：新增商品保存后自动清空表单并聚焦到名称框，适合批量录入
- **行内改价**：在商品列表中双击价格单元格直接修改
- **搜索与筛选**：按名称 / SKU / 条码搜索，按分类筛选，支持多种排序方式
- **数据备份**：手动备份 / 恢复，自动每日快照（保留最近 7 天），原子写入保障数据安全

### 🏷️ 条形码
- **多种格式支持**：EAN-13（最常用）、Code 128、UPC-A、Code 39、ITF-14
- **自动校验位**：EAN 系条码自动计算并补全校验位，输入完整 13 位时自动验证
- **矢量（SVG）生成**：条形码以 SVG 矢量图生成，任意打印尺寸都清晰锐利
- **实时预览**：输入条码内容后右侧实时显示条码图形与状态

### 🖨️ 标签打印设计器
- **可视化拖拽排版**：所见即所得的标签设计器，直接在预览画布上拖动元素调整位置
- **吸附对齐**：拖动时自动吸附到其他元素边缘、标签中心线，并显示红色参考虚线
- **多选与批量操作**：Ctrl+点选或框选多选，支持左/右/顶/底/居中对齐和水平/垂直等距分布
- **自定义文本元素**：添加任意文本（如生产日期、保质期），支持改名、复制、删除
- **日期占位符**：`{今天}` `{明天}` `{昨天}` 打印时自动替换为实际日期
- **元素旋转与竖排**：支持 0°/90°/180°/270° 旋转，以及竖排文字（每个字直立从上往下）
- **字体选择**：支持微软雅黑、黑体、宋体、楷体等系统字体
- **自动缩字**：文本超出宽度时自动缩小字号（下限 1.2mm）
- **撤销/重做**：Ctrl+Z / Ctrl+Y，支持连续同类操作合并
- **打印预设**：多套预设保存不同布局，切换预设自动切换对应的打印机和方向
- **多种标签尺寸**：60×40mm、50×30mm、40×30mm、30×40mm（竖版）、80×100mm、100×80mm，以及 A4 整页网格

### ⚡ 快速打印
- **一键直打**：勾选商品后点「快速打印」，按当前预设和上次的打印机直接输出
- **行内打印**：商品行尾的 🖨 按钮可快速打印单个商品
- **打印历史**：记录最近 20 次打印记录，支持一键原样重打

### 📄 导出 PDF
- 将当前标签版式导出为 PDF 文件（支持 A4 整页排布）

### 🔒 数据安全
- 数据文件保存在可执行文件同级目录，拷贝即迁移
- 原子写入（先写临时文件再改名覆盖）
- 每次保存前自动保留上一份备份
- 每日自动快照轮换，保留最近 7 天

## 🚀 快速开始

### 用户（免安装便携版）
1. 下载 `标印LabelPress-便携版-1.2.0.exe`
2. 放到任意文件夹（U 盘、桌面等）
3. 双击运行即可

### 开发者
```bash
# 克隆仓库
git clone https://github.com/Jaywei88/labelpress.git
cd labelpress

# 安装依赖
npm install

# 开发模式运行
npm start

# 打包为便携版
npm run dist
```

## 🛠️ 技术栈

- **Electron** — 跨平台桌面应用框架
- **JsBarcode** — 条形码生成（支持多种格式）
- **原生 HTML/CSS/JS** — 无额外前端框架，轻量高效
- **JSON 文件存储** — 便携无需数据库，自动备份与快照

├── build/                        # 应用图标
│   ├── icon.ico
│   └── icon.png
├── scripts/                      # 开发辅助脚本
└── 使用说明.md                   # 用户使用说明（中文）
